# تاجسرا — فروشگاه بدلیجات و اکسسوری مو

سایت فروشگاهی کامل برای **تاجسرا** (مدیریت: پروین آتشکار)

## ویژگی‌ها
- کاملاً فارسی و راست‌چین
- ریسپانسیو (موبایل، تبلت، دسکتاپ)
- صفحه اصلی + محصولات با فیلتر + درباره ما + تماس
- دکمه شناور واتساپ و سفارش سریع
- شماره تماس: ۰۹۳۶۰۶۶۵۶۱۶

---

## 🛒 چطور محصول جدید اضافه کنم؟ (خیلی ساده)

### روش آسان با ابزار مدیریت:

1. بعد از دیپلوی سایت، به این آدرس برو:  
   `آدرس-سایت-تو/admin/`  
   (مثال: `https://tajsara.vercel.app/admin/`)

2. فرم را پر کن (نام، دسته، قیمت، لینک عکس)

3. دکمه **ساخت کد محصول** را بزن

4. کد را کپی کن

5. فایل `data/products.json` را باز کن و کد را به آخر لیست اضافه کن

6. دوباره روی Vercel آپلود کن (یا اگر به GitHub وصل است، فقط پوش کن)

### راهنمای کامل داخل ابزار مدیریت هست.

---

## دیپلوی روی Vercel

### روش ۱: آپلود مستقیم (ساده‌ترین)
1. پوشه `tajsara` را زیپ کن
2. برو به [vercel.com](https://vercel.com) → New Project → Upload
3. فایل زیپ را آپلود کن و Deploy بزن

### روش ۲: با GitHub (بهتر برای آپدیت راحت)
1. پوشه را به GitHub پوش کن
2. در Vercel از GitHub ایمپورت کن
3. Framework را روی **Other** بگذار
4. هر بار که فایل `data/products.json` را تغییر دادی و پوش کردی، سایت خودکار آپدیت می‌شود

## ساختار فایل‌ها
```
tajsara/
├── index.html          → صفحه اصلی
├── products.html       → لیست محصولات
├── about.html          → درباره ما
├── contact.html        → تماس با ما
├── data/
│   └── products.json   → ⭐ فایل محصولات (اینجا ویرایش کن)
├── admin/
│   └── index.html      → ابزار افزودن محصول
├── css/style.css
├── js/
│   ├── main.js
│   └── products.js
└── README.md
```
